##Veck.io
A self-hosted copy of the official Veck.io Unity WebGL build, version 0.0.2482.

Original game: https://veck.io/
Official build source: https://veck.io/Build/
Streaming assets: https://veck.io/StreamingAssets/aa0.0.2482/
Cosmetic and map bundles continue to load from the official files.veck.io CDN.
The deployment workflow downloads the exact official build files and verifies their SHA-256 hashes before publishing to GitHub Pages. The ad SDK is replaced by a small no-ad compatibility shim; the game build itself is unchanged.
